# ABBA Father Worship Centre

## Project Description

The ABBA Father Worship Centre system is a church management platform designed to help church members interact with the church online.

The system allows members to register, log in, submit prayer requests, view church events, access sermons, and receive daily Bible verses.

Administrators can manage members, verify accounts, view prayer requests, and maintain church records.

## Technologies Used

- HTML
- CSS
- PHP
- MySQL
- phpMyAdmin
- XAMPP
- GitHub

## Main Features

### Member Features

- Register
- Login
- Submit Prayer Requests
- View Prayer History
- Daily Bible Verse
- View Events
- View Sermons

### Admin Features

- Admin Login
- View Members
- Verify Members
- Delete Members
- View Prayer Requests

## How To Run

1. Install XAMPP
2. Start Apache and MySQL
3. Import the database into phpMyAdmin
4. Place the project inside htdocs
5. Open localhost in your browser
