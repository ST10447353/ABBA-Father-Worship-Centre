# ABBA Father Worship Centre Mobile Application

The **ABBA Father Worship Centre Mobile Application** is a mobile church management application designed to provide church members with convenient access to church services and information directly from their mobile devices.

## Project Description

The application allows members to create accounts, log in securely, submit prayer requests, view their previous prayer requests, access daily Bible verses, view upcoming church events, and access sermons.

The application also provides administrative functionality for managing registered members and prayer requests.

## Main Features

### Member Features

* **Registration** – New members can create an account by providing their details.
* **Login** – Registered members can securely log in to access the application.
* **Prayer Requests** – Members can submit prayer requests to the church.
* **Prayer History** – Members can view their previously submitted prayer requests and the dates they were submitted.
* **Daily Bible Verse** – Members can receive an inspirational Bible verse to encourage their daily spiritual growth.
* **Church Events** – Members can view upcoming church events and activities.
* **Sermons** – Members can access sermons and church messages through the application.

### Admin Features

* **Admin Login** – Administrators can securely access the administration section.
* **Manage Members** – Administrators can view registered church members.
* **Verify Members** – Administrators can verify newly registered member accounts.
* **Delete Members** – Administrators can remove member accounts when necessary.
* **Manage Prayer Requests** – Administrators can view prayer requests submitted by church members.

## Purpose of the Application

The purpose of the mobile application is to improve communication between ABBA Father Worship Centre and its members by providing important church services and information in one convenient mobile platform. It allows members to stay connected with the church, submit prayer requests, receive spiritual encouragement, and keep up with church activities.

## How to Run

1. Open the project in Android Studio.
2. Connect an Android device or use an Android emulator.
3. Ensure the required backend/database services are running.
4. Build and run the application.
5. Register or log in to access the application's features.
